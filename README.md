# Zomato Restaurant Analysis

## Project Overview

This project analyzes Zomato restaurant data to understand
restaurant types, ratings, online ordering, table booking,
votes, and restaurant costs.

## Tools Used

- Python
- Pandas
- Matplotlib
- SQL
- Power BI
- Excel

## Project Workflow

1. Data Cleaning using Python
2. Exploratory Data Analysis
3. SQL Analysis
4. Power BI Dashboard
5. Business Insights
